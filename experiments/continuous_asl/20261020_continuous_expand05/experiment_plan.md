# Expanded continuous ASL word-gloss experiment

This is a new research experiment. Prior expand03 and expand04 fitting outputs stay frozen. It extends the existing Candidate01 raw-v1 → causal378 → causal TCN CTC pipeline; no production schema, feature blocks, runtime thresholds or Android assets change.

Use every accepted unique sample in the expanded training pool. Keep the original nine development recordings, targets and feature hashes unchanged. Never fit prior validation/quarantine samples or either test pool. Newly reserved recordings are identified before fitting; they are unique source recordings, but share historical source collections and have incomplete signer identity evidence. Do not describe the test as signer- or collection-independent. Old exposed14 test results remain unchanged and are not re-evaluated.

The versioned target policy now includes authentic source fingerspelled-word labels such as `fs-JOHN`, retained as complete source word labels rather than split into letters. Structured legacy events are admitted only when media basename, collection and the complete gloss string exactly match the official index. Preserve case, punctuation, locus notation and original timing coordinates. Those legacy coordinates are not calibrated to the current container; do not use them as invented millisecond boundaries. Reject ambiguous/unreadable/nonfinite/duplicate/CTC-infeasible samples.

Predeclared fitting: same seed20261020, identical TRAIN-only vocabulary and normalization within the pair, FP32, batch4, accumulation2, AdamW lr0.001, weight decay0.0001, clip5. Each channel width48/24 gets max30epochs/180seconds, patience10, selection by unchanged DEV WER then loss, fixed greedy CTC blank0. RF61. Start with one-epoch smoke, run targeted data tests, retain every epoch checkpoint and optimizer/RNG state. Sample whole-GPU memory/utilization every200ms alongside per-batch free-memory checks and PyTorch allocator peaks. No hyperparameter sweep or TEST tuning.

Evaluate the frozen expand03 baseline and new models with identical original9DEV inputs, raw targets, decoder and evaluator. The historical baseline has a different TRAIN-only output vocabulary/normalization, so this compares expanded training regimes and cannot isolate architecture effects. After selections are frozen, evaluate new reserved test recordings once, without using them for checkpoint/model selection. Record S/D/I, OOV references, actual durations, throughput and checkpoint SHA256 values. CPU model latency uses two threads,5warmups/20repeats per original DEV sequence; it is not application latency or camera FPS.

BU private research terms govern these data. Further corpus sources must have verified annotations, permitted research use and accessible official payloads. Keep the aggregate acquired raw/annotation/page data below2GiB, including the existing How2Sign Validation archive and previous NCSLGR acquisitions. Keep10GiB disk headroom. How2Sign English translations are not gloss labels.
